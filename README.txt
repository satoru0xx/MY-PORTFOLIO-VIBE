NAMISH MAHAJAN (satoru0xx) - PORTFOLIO SETUP GUIDE
==================================================

1. EXTRACT THIS ZIP FIRST:
   Right-click this ZIP file and select "Extract All..." into a normal folder before opening index.html.

2. ADD YOUR AVATAR & SONG:
   Place these two files right next to index.html inside the same folder:
   - avatar.png  (Your cloud-with-halo profile picture)
   - teapot.mp3  (Lukrembo - Teapot MP3 audio file)

3. EASY CUSTOMIZATION:
   Open index.html in VS Code or Notepad and scroll to the "PORTFOLIO_CONFIG" block inside <script>.
   You can easily edit your name, age, song filename, typewriter roles, skills, and buttons from that single block!

4. HOSTING ONLINE:
   Drag and drop the extracted folder (containing index.html, avatar.png, and teapot.mp3) onto Netlify Drop or GitHub Pages.
