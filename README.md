# namish-portfolio

Personal developer portfolio and interactive bio card for Namish Mahajan (`@satoru0xx`). Engineered from scratch using vanilla HTML5, CSS3, and JavaScript without external libraries or frameworks.

**Live Site:** [namish-portfolio.netlify.app](https://netlify.app)

## Features
- **Interactive Entry Gate:** Custom boot screen designed to handle browser audio autoplay policies cleanly.
- **3D Tilt & Glare Physics:** Perspective-driven glassmorphic card with real-time cursor light tracking.
- **Canvas Particle System:** Dynamic constellation network featuring mouse-proximity links, cursor trails, and click shockwaves.
- **Ambient Audio Controller:** Integrated audio player with continuous looping, volume control, animated equalizer bars, and a Web Audio API fallback.
- **Live GitHub Integration:** Asynchronous fetch module pulling repository counts and recent projects directly from the GitHub REST API.
- **Config-Driven Architecture:** Centralized configuration object for rapid updates to profile metadata, skills, and social links.

## Tech Stack
- **Markup:** HTML5, Canvas API
- **Styling:** CSS3, Custom Properties, Glassmorphism, Keyframe Animations
- **Scripting:** Vanilla JavaScript (ES6+), GitHub REST API, Web Audio API
